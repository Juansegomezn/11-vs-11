# Mejor 11 vs 11

App web interactiva para armar y comparar equipos de fútbol, inspirada en el reto de La Cobra vs Davo Xeneize.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Supabase, Groq y Framer Motion.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Completa las variables de `.env.local` con las credenciales de tus proyectos de Supabase y Groq.
